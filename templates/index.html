HOW IT WORKS

三步搞定一个落地页

不需要懂代码，不需要重新部署，改完立即生效。

01

上传模板文件

把做好的 HTML / CSS / JS 放进 templates/ 文件夹，支持拖拽上传或在线新建。

02

代码里写占位符

在需要改动的地方写 {{ key }}，例如 {{ contact_phone }}、{{ brand_color }}、{{ hero_title }}。

03

后台改变量值

后台改任何变量，前端页面自动更新。改电话、改图片、改文案，全部即时生效，无需发布。

CORE FEATURES

四大核心能力

围绕"改内容"这一个动作设计，简单到不需要培训。

变量管理

添加任意变量：文本、多行文本、图片、链接、颜色、数字。改一个值，所有引用它的页面立刻生效，无需重新部署。

模板文件

内置在线编辑器（CodeMirror 高亮 HTML/CSS/JS），支持上传、新建、删除模板文件；右侧实时显示本页用到的变量。

表单数据

访客表单提交自动收集，记录 IP、设备、浏览器、来路；支持日期 / 状态筛选、线索跟进，一键导出 CSV。

系统设置

修改管理员密码、更换后台访问入口增强安全性，配套环境检测与安装向导，开箱即用。
